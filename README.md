Business Intelligence & Operations Analyst portfolio focused on pricing, revenue analytics, process improvement, automation, and practical software systems.

## Stack
- Python / Flask
- HTML / CSS / Vanilla JavaScript
- Vercel
- JSON-backed project data

## Run locally
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
